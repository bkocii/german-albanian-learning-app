# A1 starter audio recording script

Record each phrase as a separate file in a quiet room. Speak naturally, clearly, and only once.
Leave about 0.3 seconds of silence before and after the phrase.

| Filename | Phrase | Approximate duration |
| --- | --- | --- |
| `guten-morgen.m4a` | Guten Morgen. | 1–2 seconds |
| `ich-heisse-arta.m4a` | Ich heiße Arta. | 2–3 seconds |
| `mir-geht-es-gut.m4a` | Mir geht es gut, danke. | 2–3 seconds |

Use a fluent German speaker. Listen for clipping, background noise, unnatural pauses, and correct
vowels and consonants. Replace `creator` in `manifest.json` with the speaker's name or agreed
credit before import.
